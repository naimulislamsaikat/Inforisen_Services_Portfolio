# Inforisen Services Portfolio

A modern, responsive portfolio website showcasing digital services and solutions built with React and Vite.

## Overview

Inforisen Services Portfolio is a professional web application designed to present services, projects, and expertise in a visually compelling manner. Built with cutting-edge technologies, it provides an optimal user experience across all devices.

## Technologies Used

- **React** - Progressive JavaScript library for building interactive user interfaces
- **Vite** - High-performance build tool with instant Hot Module Replacement (HMR)
- **JavaScript** - Core application logic
- **CSS** - Modern styling with responsive design principles
- **Oxlint** - Fast JavaScript linter for code quality assurance

## Project Structure

```
src/
├── components/     # Reusable React components
├── pages/          # Page components
├── styles/         # CSS stylesheets
├── assets/         # Images and static assets
└── App.jsx         # Main application component
```

## Features

- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Fast Performance** - Vite's optimized build process ensures rapid load times
- **Hot Module Replacement** - Instant updates during development
- **Modern UI/UX** - Clean and professional interface design
- **SEO Optimized** - Semantic HTML for better search engine visibility

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/naimulislamsaikat/Inforisen_Services_Portfolio.git
cd Inforisen_Services_Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

This generates an optimized production build in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
